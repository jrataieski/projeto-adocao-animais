# Sistema municipal de adoção de animais

Projeto acadêmico do Grupo 2 para organizar animais resgatados, adotantes e adoções.

## Código

- `animal.py`: classe base `Animal` (a integrar com a implementação da Claudia).
- `classes_animais.py`: classes `Cachorro` e `Gato`, feitas pela Júlia.
- `cadastro_animais.py`: funções para cadastrar cachorros e gatos pelo terminal.
- `adocao.py`: classes `Adotante` e `Adocao` (a integrar com a implementação da Thais).

As classes em `classes_animais.py` esperam que `animal.py` forneça `Animal(nome, especie, idade)`.
